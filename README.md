# Joshua Hoban — Portfolio

Live at [joshuahoban.dev](https://joshuahoban.dev)

A static personal portfolio built with React and TypeScript, deployed on Vercel.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4

## Project Structure

```
portfolio/
└── frontend/   # React/Vite app
```

## Local Development

**Prerequisites:** Node.js 20+

```bash
cd frontend
npm install
npm run dev
```

Runs on http://localhost:5173

## Deployment

Deployed to Vercel. Set the root directory to `frontend` when importing the repo.
